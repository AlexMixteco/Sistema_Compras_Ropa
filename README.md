# Sistema_Compras_Ropa
## Objetivo
Ofrecer un sitio web para la marca de ropa que permita a jóvenes comprar ropa y playeras de diseño propio de forma rápida, segura y sin depender de tiendas físicas o intermediarios.

Objetivos específicos:
- Dar a conocer la marca y sus diseños a un público joven mediante un catálogo digital atractivo.
- Facilitar el proceso de compra (catálogo, carrito, pago) en un solo lugar.
- Construir una base de clientes recurrentes mediante cuentas de usuario, historial de pedidos y comunicación directa (promociones, lanzamientos).

## Descripción general
Sitio web de comercio electrónico para una marca de ropa con diseños propios, dirigido a un público joven. Permite explorar el catálogo, agregar productos al carrito, pagar en línea y consultar el historial de pedidos desde una cuenta personal. Además, fortalece el posicionamiento de la marca y genera un canal de ingresos recurrente.
